# hazy-days
A pixel-art iOS haze widget for Singapore built using Scriptable.

## Features

- Live PSI readings
- North / South / East / West / Central regions
- Automatic haze-status detection
- Pixel-art backgrounds
- Displays the latest API update time
- Configurable region using Scriptable widget parameters

## Built With

- JavaScript
- Scriptable
- data.gov.sg PSI API
- Pixel art illustrations 

## Setup

1. Install Scriptable on iOS.
2. Create a new Scriptable script.
3. Copy the contents of `haze-days.js`.
4. Copy the contents of image-uploader into another new Scriptable script.
5. Run the script to import the images from the `assets` folder into Scriptable.
6. Name the images as named in the `assets` folder.
7. Add a Scriptable widget to your Home Screen.
8. Select the hazydays script.
9. Set the widget parameter to:
   `west`, `east`, `north`, `south`, or `central`
